## 2. arXiv submission (suggested: primary cs.DB, cross-list cs.IR)

1. Log in / register at arxiv.org. **Endorsement is very likely not required**: arXiv auto-endorses authors who
   have already announced a paper in the category, and you are a co-author of arXiv:2605.02171 (cs.DB). Start
   the submission; only if arXiv still asks for an endorsement code, see `docs/research/letter-to-quiver-authors.md` §C.
2. `Start new submission` → licence (**Creative Commons Attribution 4.0**) → category **cs.DB**, cross-list **cs.IR**.
3. Upload `quiver-reexamination.tex` **and** the `figures/` directory (keep the relative paths
   `figures/figN-*.pdf`). `paper.md`, `abstract-short.txt` and this README are not needed by arXiv.
4. Paste `abstract-short.txt` into the metadata **Abstract** box (the PDF's own abstract is longer and stays
   in the paper).
5. Let arXiv compile, inspect the generated PDF, then submit.

## 3. Build notes (why the pipeline does what it does)

* Figures are converted **SVG → PDF** with PyMuPDF because XeTeX cannot read SVG.
* Figure numbering is **manual** (`**Figure N.**` in the captions, `\captionsetup[figure]{labelformat=empty}`)
  so the numbers match the `figN-*` file names and the §11 references; re-ordering figures therefore means
  editing captions in the section files.
* Unicode mathematics (`≤ ≥ ≈ ⇒ Δ μ …`) is mapped to LaTeX math at build time; **code blocks and headings are
  ASCII-downgraded** because Latin Modern's monospace font lacks those glyphs and PDF bookmarks forbid math.
  The build **fails loudly** (prints a warning list) if any missing-glyph warning remains.
* `--toc` but **no** `--number-sections`: the section headings already carry their own numbers, and the text's
  `§11.3a`-style cross-references must stay valid.
