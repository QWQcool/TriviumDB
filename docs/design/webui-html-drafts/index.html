TriviumDB · 设计稿选择

先选完整设计稿，再进入开发。

这一批设计稿是按 Gemini 初稿与讨论稿重新整理的可浏览 HTML 原型。它们不连后端、不改产品代码，只用于确定信息架构、密度、材质和图视觉。选定某一张后，再按该稿进入实现。

V2 · 星尘侧栏 × 星夜图探索

当前推荐

按你的选择合成：保留 A 的对象导航侧栏，把主舞台切到 B 的强图视觉；另加悬浮查询舱、右侧详情/投影和底部结果抽屉。

· 定位 B 负责图，A 负责导航与壳层
· 新增 顶部查询舱 / 底部结果抽屉 / 动效开关
· 参照 Sigma.js / G6 / Cytoscape / react-force-graph / vis-network / Reagraph
打开设计稿 → 建议作为主候选

A · 星尘控制台

壳层参考

贴近现有控制台：四区工作台、TQL 编辑器、结果表、右侧节点详情。材质是暖黑曜石 + 星尘背景，适合作为全产品的默认壳层。

· 改动最小 布局保留，品牌与侧栏升级
· 重点 编辑器/结果表/节点详情的信息层级
· 风险 低，可直接落到当前单文件 UI
打开设计稿 → 对应现有 queryPane

B · 星夜图探索

图视觉候选

采用你喜欢的参考图方向：深空底、发光节点、渐变边、悬浮信息卡、向量投影。适合只用于图探索器，不建议把整套控制台都改成霓虹。

· 改动最大 图画布视觉与动效重写
· 重点 节点 glow、渐变边、选中态、右下投影
· 风险 高，需性能降级与浅色另作处理
打开设计稿 → 对应 Graph Explorer

C · 暖石浅色图

浅色对照

白天模式不走星空，保留暖纸、细网格、深金棕边线和文字 Halo。用于验证浅色下节点标签、边线和详情面板的可读性。

· 改动中等 只处理浅色图与详情面板
· 重点 #5f523b 边线 + 文字描边 + 三模深色阶
· 风险 低，和星夜图视觉共存
打开设计稿 → 对应 light theme

D · 组件状态板

开发基准

按钮五态、三模胶囊、输入框、结果卡与动效分镜。选定页面后，这一页作为组件级实现基准，避免每张图单独发挥。

· 用途 统一按钮/标签/输入/卡片规格
· 重点 hover / active / focus / disabled
· 风险 低，作为视觉回归参照
打开设计稿 → 对应 component system

建议的选择方式

当前优先看 V2：它已经按你的偏好把 B 的图视觉放到主舞台，同时保留 A 的对象导航侧栏。若 V2 通过，A/B/C/D 不再单独落地，而是作为 V2 的局部参照：A 管导航与查询台，B 管图画布，C 管浅色，D 管组件状态。
