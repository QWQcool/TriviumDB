先统一基础 token，再处理组件例外。避免继续把修补规则堆在样式表末尾。下面的色块跟随页面主题切换。

操作、文字与密度

主按钮统一 32px 高、6–8px 圆角；仅“运行 / 检索”使用强调填充。加载、格式化、导出为次级按钮，帮助与教程为低强调入口。可点击行为都应有明确文字。

UI：Segoe UI Variable Text / Microsoft YaHei；数据：Cascadia Mono / Consolas。正文 12–13px，空态标题 16px，代码 13px / 21px。衬线风格不用于功能空态；无需下载字体。

语义不随主题改变

青色表示主操作与聚焦；绿/金/红仅表达成功、警告与错误，并同时显示文字。三模数据色与 degree 半径仍用于图信息编码，不能把所有节点换成主按钮青色。

暖石浅色继续保留，不翻成冷白。暗色/浅色共享相同层级与间距，主题切换只映射材质。图舞台保留原星空与网格。

实现映射：复用旧变量，补充操作角色。

将表内 app/surface/secondary/inset 映射到现有 --bg-*；新增 --action-bg / --action-fg / --action-hover / --control-border。运行按钮使用动作语义，--success 留给状态。同步 :root 与 [data-theme="dark"]，显式设置 dark/light color-scheme。先审计所有继承点，再处理硬编码的 cockpit/dock，不用全局滤镜或 opacity 抹平差异。

V4 分三批落地

当前只交付设计参考。开发顺序从材质到工作区，再补状态与回归；每批独立小步提交。

V4-A / P0

材质与操作 token

统一基础暗色底与边线；补 action / on-action；检查教程、运行、加载、对话、弹窗的按钮层级。同步原生 color-scheme。不要只给两块红框加覆盖色。

入口：:root、theme 作用域、.btn-*、表单与导航。提交前检查图浮层与详情是否被 token 改动影响。

V4-B / P0

TQL 与向量工作面

对齐编辑器、toolbar、results-tabs、表头、JSON 与向量 summary/config/results。统一空态字级、输入内凹层和候选节点列表。沿用现有编辑器高亮与字段约束。

入口：#queryPane、#vectorLabPane、.vl-*、.empty-cta。保留所有 id、事件与布局断点。

V4-C / P1

状态矩阵与完整验收

覆盖未运行、零结果、有结果、加载、错误、禁用、聚焦、选中。核查全屏、图浮层、右侧详情与窄屏表单；定稿后统一更新受影响基线。

新增 TQL 空态/有数据、Vector 空态/有数据、候选列表焦点与错误状态截图；不能以图径向基线替代工作区检查。

与已完成 V3 的边界

V3 继续作为图舞台、屏幕字号、fit 与 1k 护栏的验收依据。V4 补齐工作区设计，不重做 B 力学；不改 HTTP 契约、PCA、分数算法、输入校验或依赖方式。语义字段、触摸操作、FPS/glow 后续问题另列，避免视觉统一变成一轮功能重写。

不只验“颜色变了”

原有回归继续执行。新增断言必须证明跨区域的 token 与状态一致，而非只匹配某个常量。

  • 三个主页面，暗浅两套主题截图含主内容与外壳；TQL / 图探索 / 向量页切换不出现旧暖黑面板。深空仅用于壳层和图舞台，不铺进表格与编辑器。
  • 表单原生状态与颜色模式Windows Chromium 下测试 select / option / checkbox / number 输入的未选、选中、禁用、键盘聚焦；主题切换后 computed color-scheme 与实际控件同步。
  • 对比度与可读性常规文字目标 ≥4.5:1，必要控件轮廓与焦点目标 ≥3:1。计算原型 token 的对比度只是初筛，产品叠层/透明度/系统控件需另验。
  • 响应式与输入完整性1440 / 1024 / 390 无页面横向溢出；长英文、中文、长 TQL 和 JSON 换行正常。表格可在自己的容器横向滚动。
  • 编辑与操作不回退tqlInput / editor-highlight 同字体、行高、padding 与滚动；候选加载、JSON 来源、top_k、min_score、查询执行、抽屉选择、导出保持原语义。
  • 保护既有测试与性能11 单元 + 29 契约、selftest 136+、ui-smoke、P1/light/detail、B 几何脚本、0 漂移、1k 护栏与基线 ≤1.5%。修改嵌入 HTML 后必须重建 Rust。
  • 国际化与测试锚点实现新增文案进入 I18N / I18N_EXT 的 zh/en 两套字典；V2-MAPPING §4 与现有 233 个 id 保留。该原型界面文案已提供 zh/en 示意。
  • 开发与验收记录分开原型数据不得写成真实检索或性能结果；先审阅 V4，再实施产品变更。PR 仍由用户最终审核后手动创建。
