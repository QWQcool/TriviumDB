## 2. 复现方法（严格照论文口径）

论文的 *Practical Compatibility Test*：对约 N 个样本向量，算「**BQ 排序 vs float32 排序的 brute-force top-K 重叠率**」。

本脚本实现为：取确定性随机子样本 `idx`（`|idx| = S`），对每个查询**在同一样本内**分别取
`float32` 的 top-10 与**码**的 top-10，算重叠率，跨 200 查询取均值。
⇒ **两侧都在同一子样本内排序**，这正是论文那句话的字面含义。

**守卫**：
- 分析式恒等式 vs `src/index/bq.rs` 逐位实现：最大差 **0**（PASS）；
- **全局口径列**（`S = 全量` 时码 top-10 vs 数据集自带 GT）必须复现 P1 的 `code_only_top10_{w,c}`：
  cohere `67.45/68.40` vs P1 `67.75/68.30` ✓、gist960 `0.70/6.55` vs `0.75/5.85` ✓、
  gist960c `28.55/23.15` vs `28.65/23.90` ✓、gauss960 `17.85/0.65` vs `16.70/0.85` ✓、
  glove100 `32.30/19.55` vs `33.55/22.90` ✓、sift128 `3.10/10.05` vs `3.50/10.30` ✓、sift128c `22.70/24.35` vs `23.00/23.25` ✓
  —— 差异 ≤1.2pp（整数 Hamming 并列导致的 argpartition 并列打破差异）；
- 全量时"样本内 f32 top-10"∩"数据集 GT"：sift128/gist960/gauss960/gist960c/random/sphere `≈100.00%`，
  **glove100 只有 `84.85%`**（⚠️ 见 §5-限制 2）。

### 2.3 ★ 与论文自己的数字对拍
论文 Table 10（编码消融，**Cohere-100K**，2-bit SM）报告 **top-10 overlap = 64.7%**。
我们 `cohere` 在 `S=100K`：**weighted `63.20%` / cheap `61.55%`**（Δ = −1.5 ~ −3.2pp）。
⇒ **口径打通**：论文的探针在我们手上可复现到 3pp 内。

## 4. 三条具体可写的批评（对已发表判据）

### 4.1 判据**未指定 BQ 度量**，而两个度量会给出**相反结论**
| 数据集 | `weighted`（建图度量） | `cheap`（**查询 L0 度量**） | 实际召回 |
|---|---|---|---|
| **random（Synthetic-LR）** | **66.95%** ⇒ "兼容 BQ-native" | **45.25%** ⇒ "更安全的是 float32" | 43.60%（论文归"可用档"） |
| sphere / gauss960 | 29.9% / 17.9%（全量） | 5.1% / 0.65% | 0.48% / 0.41% |

⇒ 论文的部署判据**不是一个良定义的函数**：同一个数据集，换个度量就从"go"变成"no-go"。
**修正建议**：**两个度量都算并取弱环**（`min`）。本表 `min(w,c)@10K` 的 ρ = **+0.9500**（与 cheap 同分，
但它在"建图度量才是瓶颈"的行上更保守——如 gist960，w=4.20 把 min 拉到 4.20）。

### 4.2 探针**强依赖样本量**，且方向是"样本越小越乐观"
- 极端：gauss960 cheap `4.40%（10K）→ 0.65%（全量）`＝ **6.8×**；sphere `5.05 → 0.80`＝6.3×。
- 后果：论文规定的 **50% 阈值**在小样本下**更难触发警报**。例如 sphere 在 `S=10K`、`weighted` 下读作
  **`29.85%`**（离 50% 只有 20pp），而它在 1M 上的真实行为是 `0.48%` 召回。
- ⇒ 论文写"约 10K 样本"，但未说明**为什么 10K 够**；我们的曲线说明**必须**绑定 `S`，
  且最好直接报告"同分布全量"值（我们已给出全局口径列）。

### 4.3 把"崩塌档/竞争档"从**事后标签**变成**先算后测**（P1+P2 合并结论）
论文 Figure 3 的四档是**按观测召回划的**（事后标签，桶内无语义分辨力）。
经 P1（证伪 SNR）与 P2（确认探针）后，可用的**先算后测**组合是：
1. **`min` 两度量的码 top-10 命中率**（ρ=0.95，本报告）——论文探针的"弱环版"；
2. **`L0 ∩ cos_top64`（图保真度）**——码侧探针**看不见**的那条轴
   （gist960：码命中率还有 6.55%，但图对 cosine 保真度只有 **0.57%**，cohere 为 56.84%）；
3. **`GT10 − GT11`（任务可解性）**——用于"无结构档"（sphere/gauss960 的近并列）。

## 5. 限制声明

1. **只有 9 行，其中论文的 12 行只有 6 行**（cohere / glove100 / sift128 / gist960 / random-Synthetic-LR /
   sphere-Random-Sphere）；缺 `minilm-384` / `wolt-clip-512` / `redcaps-512` / `bge-m3-1024` /
   `dbpedia-1536` / `dbpedia-3072`（**其中 `redcaps-1m` 在本仓 registry 里不存在**，是否可复现未知）。
   ⇒ **"竞争档"目前只有 1 行（cohere）**，P2-2 的"可分"判定样本极薄。
2. **`glove100` 的"样本内 f32 top-10"与"数据集自带 GT"只有 `84.85%` 一致**：
   我们重算的归一化数据 top-10 与 HDF5 原生 angular GT 有 ~15% 分歧 ⇒
   glove100 的召回数字（无论我们的 `32.82%` 还是论文的 `32.08%`）都带有 **GT 口径模糊性**。
   其他 6 个数据集 ≈100%，故该问题**仅限 glove100**。
3. **`S=全量` 时 `idx` 是一次随机置换**（`choice(n, n, replace=False)`），与 P1 的"整数组不动"在
   整数距离并列处打破方式不同 ⇒ 全局口径与 P1 有 ≤1.2pp 差异（已逐行对拍，见 §2 守卫）。
4. **口径差异**：论文的"10K 样本"是**样本向量**数；我们按"子样本候选集"实现，**未**把查询也限制在样本内
   （查询仍来自测试集）。若论文的意图是"从库里抽 10K 一起当库"，则与本文一致；否则需重核。
5. 单机、无 AVX-512；召回与 SIMD 无关，但 **QPS 不可比**。
6. 论文数字为 arXiv HTML 抓取转述（**未与 PDF 逐格复核**）。
