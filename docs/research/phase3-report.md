## 4. 本阶段新增的关键数字

* **`randomc`（Synthetic-LR，可用档第二个代表）—— 修复后在 centered 任务上"同召回快 7.6–8.9×"**：

  | 匹配点 | QuIVer 流水线（去均值+加权导航） | hnswlib（同 centered 任务） | 同召回 QPS 比 |
  |---|---|---|---|
  | ~51 % | **53.61 %** @34,288 | 51.37 % @3,859 | **≥8.9×** |
  | ~68 % | 69.29 % @18,429 | 67.66 % @2,176 | 8.5× |
  | ~82 % | 82.43 % @9,834 | 82.17 % @1,203 | 8.2× |
  | ~92 % | 91.79 % @5,097 | 92.05 % @652 | 7.8× |
  | ~97.4 % | 97.05 % @2,638 | 97.40 % @349 | 7.6× |

  `faiss_exact` = 100.00 % ⇒ 无并列地板。⚠️ **诚实标注**：竞品曲线只在 **centered 任务**上测过，
  所以这是"修复后在该任务上支配"，**不能**说成"去均值把该档从被支配翻转成胜"（修复前的同任务竞品曲线未测）。
* `spherec`：HNSW **也崩塌**（hnswlib 1.40 % @3,645、FAISS-HNSW 1.49 %、USearch 1.68 %，USearch 建图 **1,737s**），
  而 `faiss_exact` = 100.00 % ⇒ 判定是**任务不可分辨**而非编码问题。
* 由这两条得到论文 §6.4 的"**两种崩塌**"表（码特有 vs 索引无关），这是本阶段对论文最有价值的一条。
