## 1. P4-A ✅ **旋转 vs 去均值头对头**（本阶段核心，已写入论文 §8.6/§9.2/§10）
**文档**：`p4a-rotation-vs-centering.md`

| 结论 | 数字 |
|---|---|
| 种子随机旋转**保任务**（可验证） | GT ∩ 原 GT = **99.87–100%**；`max|QQᵀ−I|` ≈ 1e-15；零存储（dim+seed 足够） |
| 崩塌档：旋转**强于**去均值 | GIST `2.10 → **60.22%**`（去均值 39.74）；SIFT `15.77 → **60.24%**`（去均值 30.64）@ef=64；@1024 达 **88.99% / 95.74%** |
| 但**不是通用修复** | 竞争档 Cohere `94.63 → 89.82%`（**−4.8pp**）；可用档 GloVe 需配加权导航（54.06% @ef=64） |
| 机制 | 旋转**复活符号面**（`sign_info` 0.000→0.507/0.759）同时**摊平幅度面** ⇒ 幅度面"有害"时纯赚，有用时净亏 |
| 竞品判定**翻转** | GIST-960：84.41% @7,148 vs hnswlib 84.11% @5,417 ⇒ **快 1.32×**；且 **60–84% 召回带内 HNSW 无工作点**（其最低 ef=64 已 84.11%）⇒ 从"差距 79.7pp 严格支配"变为"**在中召回带唯一可用 + 两端更快**"。SIFT 仍被支配，但差距 **49.9 → 1.7pp** |
| 建造成本 | 建图**快 2–6×**（GIST 290→47s、Cohere 202→31s） |
| ★ 判据升级 | 同一支码探针还决定**导航度量**：`probe_ef(加权) > probe_ef(Hamming)` ⇒ 用加权。**10 臂 9 一致**（唯一不符者两量都在噪声内），且修好了 `sign_info ≥ 0.75` 在 `sift128r` 上的失效 |
